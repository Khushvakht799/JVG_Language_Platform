# Демо: передача смены в дата-центре

`datacenter_shift_handover.jvg` — безопасный демонстрационный сценарий для JVG Operations Platform.

## Что показывает демо

Сценарий ведёт исходящего и входящего инженеров через передачу контекста:

1. открытые инциденты и изменения смены;
2. критические риски и их владельцы;
3. подтверждение принятия входящим инженером;
4. создание проверяемого аудит-следа или эскалации.

Это **не** система управления оборудованием. JVG не посылает команд на инфраструктуру: он проверяет полноту процедуры, фиксирует подтверждения и направляет исключения человеку.

## Состояния

`ПОДГОТОВКА` → `СБОР_КОНТЕКСТА` → `ПОДТВЕРЖДЕНИЕ_ВХОДЯЩЕЙ_СМЕНЫ` → `ЗАВЕРШЕНО`

При неподтверждённом критическом пункте или отказе от принятия:

`СБОР_КОНТЕКСТА` / `ПОДТВЕРЖДЕНИЕ_ВХОДЯЩЕЙ_СМЕНЫ` → `ЭСКАЛАЦИЯ`

```powershell
python -c "import json; json.load(open('05_examples/datacenter_shift_handover.jvg', encoding='utf-8')); print('JVG JSON is valid')"
```

## Критерии результата пилота

- все критические пункты имеют владельца и подтверждение;
- журнал содержит время, роль, действие и результат;
- неподтверждённая передача не может быть завершена;
- решение работает как помощник инженера и не принимает операционные решения за человека.
